# 维维美统一记忆与 PRTS 更新

## 已落实的行为

- 新版源码和新版独立程序统一使用 `%LOCALAPPDATA%/Maagent` 的记忆、知识库、物品图标目录和截图。可用 `MAAGENT_DATA_DIR` 或 `agent.data_dir` 指定另一整套数据目录；单个旧文件路径仅作首次迁移来源。
- 首次迁移备份旧文件，按内容合并记忆，优先保留用户目录数据；归档冲突默认服规则及旧职业排列记录。迁移标记防止后续启动重新导入已删除的记忆。
- 默认 B服，打开后自动进入主界面。仅明确指定官服时使用官服。
- 查找干员前先读取知识库文档中的职业；职业缺失或筛选失败则停止，防止凭猜测继续。查询练度仍复用现有识别流程，准确性留待后续实机训练。
- 核心规则常驻提示，不再因追加超过 15 条普通记忆而被挤出。记忆和知识库通过文件锁及原子替换写入，读取时重新加载其他新版实例的更新。
- 对话工具 `update_prts_knowledge` 从 PRTS MediaWiki API 获取干员或敌人页面，校验分类与必要字段，保存原始字段及页面正文、来源 URL、抓取时间、修订号。失败保留旧资料；网页内容作为资料，不作为执行指令。

## 可以使用的指令

自然语言示例：

- “从 PRTS 更新芬的资料并保存到知识库。”
- “更新源石虫的敌人数据。”
- “更新干员知识库。”（工具分批返回进度；单轮模型步数有限，未完成时需继续。）

不依赖模型理解的对话窗口命令：

```text
:prts 干员 芬
:prts 敌人 源石虫
:prts 干员 --all
:prts 敌人 --all
:prts 干员 --resume
:prts 敌人 --resume
```

名称中有空格时加引号；按名称一次最多 10 个。全量按分类每批最多 10 页，批次间保存游标和失败项。Ctrl+C 可中断，`--resume` 从上次完成的批次继续；中断批次可能重抓，按同名文档替换。失败页按名称重试；分类遍历完成不等于所有页面成功。

## 后续维护

旧源码 config 下的数据保留作历史来源，不再由新版 agent 日常读写。旧二进制不会自动获得代码改动，需要使用新版程序；不要让旧程序与新版同时修改数据。更新脚本默认也写入统一知识库，显式 `--out` 可导出到独立文件。

知识库采用关键词检索而非语义索引；网页数据的获取成功不保证每个页面布局均已覆盖。缺少必要字段的页面会列为失败，不覆盖旧资料。培养执行、活动商店及 MAA 对话接入不在本次实现范围。
