# MaaEnd 提前关闭修复

## 定位证据

已安装 Maagent 的 2026-10-18 日志及 reports.jsonl 保存了两次误判：

- 09:51:01 MaaEnd 输出「🏁 售卖任务已完成」，随后输出「任务完成: 🛒据点交易」和「任务开始: 📦自动囤货」。Maagent 在 09:51:05 判定完成，09:51:11 关闭 MaaEnd。
- 10:18:57 同样完成据点交易并开始自动囤货；Maagent 在 10:19:00 判定完成，10:19:05 关闭 MaaEnd。

原 `_is_done_message` 使用子串匹配「任务已完成」，因此售卖子任务完成被误当成整个队列完成。这两次均走日志完成分支，并非进程退出分支。

## 修复

- 完成通知仅接受整条白名单文案，移除「结束进程 + 完成」的模糊兜底。
- 后续任务开始会使之前的完成通知失效；API 明确仍在运行时不能因日志直接判定结束。
- API 未提供布尔运行标记时返回未知状态，而非 False。
- 运行态兜底必须先观测到 True，再连续三次观测到明确 False；轮询间隔 5 秒，未知或重新运行会清零计数。
- MaaEnd 的自动关闭必须同时满足用户开启自动关闭和本次完成已确认；超时、未启动与异常路径保留窗口。

验证：`python -m unittest tests.test_maaend_completion -v`，10 项通过；未执行真实游戏任务。修复位于源码，需重新打包更新桌面程序后生效。

本轮未改动工作区中其它正在开发的 agent 文件。
